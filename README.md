# Midnight Club 3 (PSP)

Pembungkus core PPSSPP (libretro) dengan Import Game.

1. Upload seluruh isi folder ini ke repositori GitHub private (branch `main`).
2. Jalankan workflow "Build APK" di tab Actions.
3. Unduh artifact `MC3-PSP-APK`, ekstrak, pasang `app-release.apk`.
4. Di app: Import Game, pilih file ISO/CSO/PBP, lalu ketuk untuk bermain.
